Jenkins CI/CD Pipeline Demo

This repository demonstrates a hands-on CI/CD pipeline built with Jenkins as part of a DevOps bootcamp.

The pipeline automates:
Pulling source code from GitHub
Building the application with Maven
Building a Docker image
Pushing the image to Docker Hub

Versions

v1.0 – Implemented using a Jenkins Freestyle job configured via the Jenkins UI.
v2.0 – Migrated to Pipeline as Code using a Jenkinsfile and script.groovy for a reproducible and version-controlled workflow.

Tech Stack
Jenkins • Maven • Docker • Docker Hub • GitHub • AWS EC2
